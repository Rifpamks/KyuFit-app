spec-driven-development — Membuat spesifikasi teknis ringkas sebelum menulis kode.
planning-and-task-breakdown — Menguraikan pekerjaan menjadi tugas-tugas kecil yang terukur (/plan).
incremental-implementation — Membangun fitur dalam irisan (slice) kecil yang terverifikasi (/build).
test-driven-development — Menjamin pengujian (Test-Driven) sebelum fitur dianggap selesai (/test).
code-review-and-quality — Audit kualitas kode 5 aksis sebelum merge/ship (/review).
frontend-ui-engineering — Best practices komponen UI, aksesibilitas, dan responsivitas.
api-and-interface-design — Perancangan API contract & interface yang konsisten.
code-simplification — Menyederhanakan struktur kode tanpa merubah fungsi (/code-simplify).
performance-optimization — Mengukur dan mengoptimalkan kecepatan web (/webperf).
security-and-hardening — Menutup celah keamanan (SSRF, auth bypass, injection).
debugging-and-error-recovery — Investigasi bug berbasis bukti log mendalam.
browser-testing-with-devtools — Pengujian otomatis tampilan dan alur via browser DevTools.
interview-me — Interogasi kebutuhan pengguna satu per satu untuk memperjelas spec (/interview-me).
shipping-and-launch — Checklist peluncuran fitur ke produksi (/ship).
idea-refine — Mematangkan ide mentah menjadi konsep fitur yang konkret.
documentation-and-adrs — Pembuatan dokumen arsitektur (ADR) dan panduan.
context-engineering — Mengelola konteks prompt dan memori AI agent.
doubt-driven-development — Validasi asumsi secara kritis sebelum mengeksekusi kode.
source-driven-development — Menggunakan kode sumber resmi sebagai kebenaran utama.
deprecation-and-migration — Strategi migrasi data/skema tanpa downtime.
observability-and-instrumentation — Penambahan metrics, tracing, dan log terstruktur.
ci-cd-and-automation — Otomasi pipeline build & deployment.
git-workflow-and-versioning — Standar commit dan branching Git.
using-agent-skills — Panduan penggunaan seluruh skill secara otomatis.
